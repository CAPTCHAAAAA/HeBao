# HeBao
模拟HENU的H5请假程序

### 项目简介
这是一款可以在手机上本地运行网页并进行修改的工具。简单来说，我们做了一个没有网络也能用的浏览器外壳，让你能在不破坏网页原本样貌的前提下，直接在屏幕上点触并修改里面的文字和图片。

### 核心功能体验
* **无缝修改文字**：优化了文字识别能力，网页里藏得再深的文字也能精准点到。开启模式后，能改的地方会泛起点淡蓝色提示。你可以连续点触、不断修改，改完后点击底部的退出按钮，网页就会瞬间恢复原样，看不出任何修改痕迹。
* **轻松替换图片**：开启换图模式后，点击网页上的图片就能直接打开手机相册。选好新照片，系统会在后台默默替换上去，整个过程流畅自然，同样支持连续换图。
* **一键切换版本**：软件内置了“有图”和“无图”两个网页版本，你可以随时无缝切换，界面底部会弹出清晰的提示告诉你当前状态。
* **更现代的界面设计**：告别了以前那种老气、生硬的系统弹窗。现在的菜单和修改面板换成了从底部滑出的圆角卡片，输入框也做了扁平化处理，点击时带有水波纹反馈，看着舒服，用着顺手。

### 性能与稳定性优化
* **告别闪退**：以前因为图片太大经常撑爆内存导致软件闪退，现在我们彻底优化了底层文件的存储和加载方式，运行更加丝滑。
* **修复白屏卡顿**：针对网页里自带的一些外部平台代码（比如微信的某些组件），我们在底层做了模拟环境，确保网页能顺利加载，不再出现一直转圈或白屏的情况。

### 外观与适配
* **全新应用图标**：重新设计了极简风格的图标，采用了非常干净的纯红底色，搭配代表“照片与文字”的纯白符号。去掉了花哨的阴影，保证在任何高清屏幕上都绝对清晰。
* **夜间模式适配**：软件的顶部栏、菜单和底部弹窗都能完美适配手机的深色和浅色模式，白天看清晰，晚上看也不刺眼。

### 安装须知
* **支持设备**：支持 **Android 14 (API 34) 及以上** 系统的智能手机。
* **安装提示**：因为这是我们独立开发的软件，没有上架应用商店，手机在安装时可能会弹窗提示“未知来源”或“未经安全审核”。这很正常，直接选择“允许”或“继续安装”即可放心使用。
