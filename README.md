# HeBao
模拟HENU的H5请假程序
⚙️ 项目概述
本项目是一个基于 Android 原生壳加本地 WebView 内核构建的离线页面管理与动态调试工具。应用通过离线资产的形式加载本地 HTML，并利用动态 JavaScript 注入与 Web 桥接技术，实现了在不破坏原始基础 UI 的前提下，对内置网页内容的实时无痕修改。

🛠️ 新增特性与功能改进
📝 持续文本编辑模式 (Continuous Text Edit Mode)

实现逻辑：采用深度优先的 DOM 树递归遍历算法，精确提取底层纯文本节点（Node Type 3），解决多层级框架嵌套下的文字无法点击问题。

交互视觉：开启后，可编辑文字区域自动覆盖一层 rgba(0, 122, 255, 0.12) 的扁平化蓝色微光，支持高频连续点触弹窗修改，点击页面底部的“退出文本编辑”按钮即可一键恢复网页原始干净状态。

🖼️ 持续图片替换模式 (Continuous Image Patching)

实现逻辑：基于 JavascriptInterface 挂载原生图片通信桥梁，绑定 GetContent 结果回调。

交互视觉：点击开启后，网页所有 <img> 标签覆盖高亮框，用户点触任意图片可直接呼起 Android 系统原生相册，选图后在子线程将其压入 Base64 流并由主线程静默更新对应 DOM 的 src 属性。

🔄 双版本离线页面切换

支持在运行期无缝切换内置的 perfect_leave_img.html（有图版）与 perfect_leave_noimg.html（无图版），并伴随“已切换至有/无图版本”的精准状态回显提示。

💎 原生扁平化交互卡片 (Material 3 Sheet)

彻底移除陈旧的系统默认 AlertDialog 弹窗。高级菜单与改字面板全部改由纯 Kotlin 代码动态绘制，提供 24dp 顶部圆角底栏卡片（BottomSheetDialog）。

输入框采用内凹式灰色扁平底色块，移除原生下划线；加入系统级 selectableItemBackground 水波纹按压反馈，文字修改面板顶部标有红色的“请注意文本格式”作为安全警示。

⚡ 稳定性及内存优化 (Stability & BugFix)

解决闪退：抛弃旧版将图片全部硬编码进 Base64 导致单文件体积过大触发的 OOM（内存溢出）闪退问题，改为 HTML 与静态资源相对路径分离存储。

环境修复：在 WebView 加载结束（onPageFinished）时，自动注入针对 window.wx（微信）和 window.campus（今日校园 SDK）的底层核心运行环境补丁，消除前端环境缺失引发的白屏与加载死锁。

🎨 主题与视觉规范 (Aesthetics)
应用图标：采用严格的 True Flat（纯扁平） 矢量几何规范，无渐变与黑圈阴影。使用纯原生 XML Vector 路径，将纯白的“图片底片”与“三条文本横线”符号利落交叠，衬托在 #FF3B30 现代标准全红底色中，任意高分屏缩放不失真。

暗黑模式：界面顶栏、气泡菜单以及底部卡片完美适配沉浸式深色主题（#191919 / #222222）与浅色主题，状态栏图标随主题自动进行轻量与暗色避让切换。

📦 运行环境与安装
生成文件：app-release.apk / app-debug.apk

最低配置：Android 8.0 (API v26) 及以上系统的智能手机。

安装说明：本软件属于独立签名封装应用，在本地安装时如遇系统安全提示“未知来源”，在安装器中点击“允许/仍然安装”即可正常启动。
